    Assembly guide & export

    The guide numbers every piece in the order to stick them on: #1 is the bottom layer (goes on first), the top layer gets the highest number. Each copy has its own step; hidden layers are skipped. Crowded spot? Click a layer's # (or untick it under Selected piece) to hide just that number, or set Numbers to None. The legend still lists every step. Print the PDF at 100%: it's the backdrop at true size (enlarged for your printer when calibration is on). Turn on "Print piece numbers" on the Layout tab to number the stickers on the cut sheet too.

    Calibrate once per printer + paper size

    Measures how the Cricut's cuts land relative to your printer's ink. It can compensate a printer that shrinks the page, then checks itself on a verification pass. Pick the sheet size on the Layout tab first.

    Calibration auto-saves in this browser. Some browsers drop data for files opened from disk, or keep it per file location (a moved or re-downloaded copy then starts empty). Keep the exported .json as a backup (Import restores it), or save a copy of the tool with the calibration built in and open that one. Save project includes it too.

    Readings

    For each target, read where the cut slit crosses the printed mm scale: the scale across the square's left edge gives X (+ = cut is right of the printed line), the one across the top edge gives Y (+ = cut is lower). The scales run from −8 to +8 mm (ticks every 0.5 mm, numbers every 2 mm). Estimate to 0.25 mm.

    Ruler check (optional), corner marks measured outside to outside: across the top down the left side (expected ; values over 50 are read as mm)

    Pass tolerance ± mm

    The fit uses all targets (least squares) to find the printer's size per direction, a small rotation and a shift. Each pass is fitted absolutely from the files that sheet was made with, so passes refine and never stack. "Misfit" is how far a reading is from that pattern. Over 1 mm, or one target that disagrees with the other four, is flagged as a bad reading or paper that moved.

    Enter values manually

    Printer shrink across (%) down (%) · Print compensation across (%) down (%)
    Cut vs print rotated clockwise (°) shifted right (mm) down (mm)

    Shrink = how much smaller your printer prints than the file (3.00% = 7.76 in instead of 8.000). Compensation = how much the tool enlarges the print PDF; true size needs 1/(1 − shrink) − 1 (3.00% → +3.09%). Rotation and shift describe the uncorrected cut relative to the ink, at the sheet centre.
